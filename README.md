# 紀の里 製造予定管理アプリ

紀の里食品向け製造予定作成アプリの実装コード（フェーズ1）。

## 構成
- `app_logic.js` — アプリ本体のロジック（画面描画・状態管理・保存処理）
- `app_style.css` — スタイルシート
- `build.js` — `app_logic.js` / `app_style.css` / マスタデータ(JSON) を1枚のHTMLに組み立てるビルドスクリプト
- `../realdata/app_master_data.json` — 商品・グループのマスタデータ（通販520品目・卸329品目）

## ビルド方法
```
node build.js
```
`../app_prototype_real.html` に単一HTMLファイルが出力されます。

## 現在の保存方式について
現状はClaudeのArtifact機能（`window.claude.use('artifact')`）でページ自身を書き換えて保存する方式です。
Netlifyなど他のホスティングに移す場合は、この保存処理をNetlify Functions等の実バックエンドAPIに差し替える必要があります
（画面描画・計算ロジックはそのまま流用可能です）。

## フェーズ1の範囲
- 通販：週次計画／月次計画／グループ並び順／印刷プレビュー
- 卸売：週次計画／月次計画（商品別合計のみ）／印刷プレビュー
- 確定／下書きワークフロー、製造メモ＋履歴
